# ANAA BASHIR – Creative Portfolio

معرض أعمال احترافي وفاخر لعرض المشاريع الرقمية والتصميم الإبداعي.

## نظرة عامة
موقع استático مصمم حصرياً لأعمال **ANAA BASHIR** – مصممة مواقع وتجارب رقمية، طالبة بكالوريوس في تحليل البيانات والذكاء الاصطناعي.

## هيكلة الملفات
```
portfolio/
├── index.html          # الصفحة الرئيسية (HERO + مشاريع مختارة)
├── about.html          # صفحة من أنا
├── projects.html       # صفحة المشاريع (شبكة المشاريع)
├── contact.html        # صفحة التواصل
├── README.md
└── assets/
    ├── css/
    │   └── style.css   # التنسيق الكامل
    ├── js/
    │   └── main.js     # الحركات والتفاعلية
    └── images/         # مجلد الصور (فارغ – الصور محددة عبر CSS)
```

## المميزات
- دعم كامل للعربية (RTL) والإنجليزية (LTR) مع زر تبديل اللغة
- وضع ليلي ونهاري
- قائمة تنقل عصرية متجاوبة
- تأثيرات ظهور تدريجي أثناء التمرير (Scroll Reveal)
- حركات hover احترافية على الأزرار والبطاقات
- مؤشر تقدم التمرير (Scroll Progress)
- زر العودة للأعلى
- تصميم متجاوب لجميع الشاشات
- تحسينات SEO أساسية (meta title, description, author)
- عدم استخدام قواعد بيانات أو نظام تسجيل دخول

## ملاحظات صور المشاريع
صور المعاينة في بطاقات المشاريع مصممة أصلية عبر CSS (لا توجد صور مكسورة أو مساحات فارغة)، وهي توضيحية لكل مشروع ولا تُClaim لقطات شاشة فعلية منه.

## كيف تشغل الموقع محلياً
افتح ملف `index.html` في أي متصفح ويب مباشرة، أو خادم محلي بسيط:
```bash
# باستخدام بايثون
python -m http.server 8000
```
ثم افتح `http://localhost:8000/portfolio/index.html`
